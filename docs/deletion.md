# 删除与数据保留

删除用于永久清理不再需要的对话或应用。没有回收站，完成后无法恢复；需要的文件、源码和业务数据请先导出或备份。

## 怎样删除

- **普通对话**：打开会话列表的行菜单，选择「删除对话」并确认。
- **应用**：从应用列表或编辑页设置选择「删除应用」，输入当前应用名称确认。

应用的开发对话随应用一起删除，不能单独删除。

删除进行中会显示进度。看到「删除未完成」时，查看原因并重试。关闭提示窗口不会取消已登记的删除。

## 会清理什么

| 对象 | 清理范围 |
| --- | --- |
| 普通对话 | 消息、执行记录、上传和生成文件、该会话的执行环境 |
| 应用 | 开发与问数对话、源码版本、构建与发布记录、预览和正式入口、运行实例、测试和正式业务数据库、访客账号与会话，以及已连接观测库中的该应用数据 |

删除一个对象不会删除个人技能、专家、MCP 连接或其他应用的共享资源。

删除应用前，应保持所用的访客认证服务、观测服务及数据库可用。观测功能关闭时，平台不会清理未连接的独立观测库；请先恢复相应配置再删除，或由管理员单独核对并清理残留。

## 哪些数据仍会保留

账务流水、必要用量和审计信息独立保留，删除不会退回余额或修改历史费用。平台保留不含聊天正文的删除结果记录，用于核对清理情况。

已下载的文件、离线备份及外部观测服务中的数据不会随在线资源一起删除，需要各自管理。

## 只是暂时不用怎么办

想保留资料时，可以关闭会话工作环境、暂停应用预览，或将正式应用下线。这些操作保留文件或应用数据，之后可以继续使用。
