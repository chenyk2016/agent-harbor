# 接入和管理模型

管理员接入模型后，成员就能在工作台选择模型执行任务。按 [安装指南](quickstart.md) 创建的实例已准备模型网关，仍需提供有权使用的供应商 API Key。

## 开通第一个模型

从首页「接入模型」或「管理后台 → 模型与网关 → 快速接入」进入向导。

1. **连接供应商。** 选择预置供应商，或填写自定义接口协议、API 基地址和 API Key。核对页面显示的请求地址。
2. **选择模型和价格。** 从列表选择上游模型 ID，读取失败时可手动输入。填写平台价格；要求供应商成本时，按页面提示填写成本。
3. **测试并启用。** 运行测试，等待网关连接、文件读取工具和流式输出通过。钱包余额不足时，可以在向导中为当前管理员补额度。
4. **试做一个任务。** 测试通过后选择该模型，按 [第一个任务](first-task.md) 上传文件并核对产物。

测试会向真实供应商发起模型请求，可能产生费用。失败后配置会保留，可按向导提示修正密钥、地址或模型后重试。

向导创建的模型默认只允许当前管理员使用。让成员使用前，打开模型详情的「使用范围」添加成员；留空表示所有用户。

## 接入时要分清的三个名称

| 名称 | 例子 | 用途 |
| --- | --- | --- |
| 供应商 | 团队模型服务 | 保存接口地址、协议和 API Key |
| 工作台模型名 | 团队日常模型 | 成员在模型选择器中看到的名称 |
| 上游模型 ID | 供应商提供的模型标识 | 实际发送给供应商的模型名称 |

同一个供应商可以接入多个模型。支持 Anthropic 原生、Anthropic 兼容、OpenAI Chat Completions 和 OpenAI Responses 协议。接口兼容不代表所有模型能力相同，工具调用和流式输出需要实际测试；图片、搜索、缓存等能力也取决于供应商与模型。

## 设置价格和使用范围

模型价格包含输入、输出、缓存读取、缓存写入四项，单位为**元 / 百万 Token**。明确免费时填 0；留空不等于免费。启用钱包后，未定价模型不能用于生成。

供应商成本使用**美元 / 百万 Token**，与平台人民币价格分别记录。保存新价格只影响后续请求，已发生的消费按当时价格保留。详见 [额度与计费](wallet.md)。

在「使用范围」搜索并添加成员，或移除不再允许使用的成员。缩小范围或停用模型会撤销相关调用权限。

## 更换模型版本或供应商密钥

需要更换上游模型或能力配置时，在模型详情发布新版本，再显式「设为当前」。已有会话从下一轮开始使用新版本，正在执行的请求保持原版本。

在供应商详情可以修改名称、API 地址或轮换 API Key。密钥保存后不回显。修改后检查同步状态；显示待核对时先处理同步，再让成员重试。协议需要改变时，新增对应协议的供应商。

## 停用和删除

暂时停止使用模型时可停用。要永久删除，先查看页面的使用检查：仍在使用该模型的会话、运行中的任务或未释放环境会阻止删除。供应商仍被尚未永久删除的模型引用时也不能删除；已删除模型保留的历史版本不会单独阻止供应商删除。

模型删除会清理网关路由，供应商删除会清理已保存密钥；历史价格、用量、账单和审计记录继续保留。

## 接入失败时检查什么

| 提示或现象 | 先检查 |
| --- | --- |
| API Key 被拒绝 | 密钥是否有效、是否允许调用该模型 |
| 找不到模型 | 上游模型 ID 是否准确，账号是否有权限 |
| 请求格式错误 | 协议与 API 基地址是否对应供应商要求 |
| 文件读取或流式测试失败 | 模型工具能力、流式支持及运行环境 |
| 网关同步待核对 | 网关连接、管理凭据和模型同步状态 |
| 没有可选模型 | 模型是否启用、是否已授权给当前用户 |

网关服务地址、持久密钥和可选预算见 [配置参考](configuration.md)。
