同一会话保留连续对话和工作文件，适合把一项工作分多轮完成。不同工作建议新建会话。

## 开始和继续任务

1. 在首页选择「对话」和可用模型，输入目标并发送；发送后自动创建会话。
2. 在对话页查看执行进度和工具记录。
3. 需要上传资料时，先等当前任务结束，再上传文件并发送处理要求。首页暂不提供上传入口。
4. 在同一对话提出补充要求，Agent 可以继续处理工作区文件。

执行中的任务结束或停止后，才能发送下一轮。遇到「运行环境待核对」时，先等平台检查；持续无法恢复请联系管理员。

## 关页面、停止和关闭环境有什么区别

| 操作 | 结果 | 适合什么时候用 |
| --- | --- | --- |
| 关闭或刷新网页 | 服务端任务继续，重新打开可查看进度 | 暂时离开 |
| 停止当前任务 | 请求结束本轮执行，已完成的文件修改仍保留 | 方向不对或不想继续执行 |
| 关闭工作环境 | 释放执行环境，保留对话与工作文件 | 需要结束环境中的进程、释放资源 |
| 删除对话 | 永久清理该对话及文件 | 确定不再保留这项工作 |

停止不会撤销已经写入的文件或已经完成的外部操作。需要恢复内容时，先核对已有结果，再决定下一步。

## 环境空闲后会怎样

默认任务结束后空闲 **15 分钟**回收工作环境。下一条消息会重新创建环境并继续已有对话。

工作区文件仍在；进程内存、临时目录和运行中的服务不会恢复。需要保留的成果应写进工作区，并及时下载。

管理员选用 OpenSandbox 执行后端时，单个会话环境还有 **1 小时**的存活上限，与空闲回收和单轮任务超时分别生效。达到上限可能中断正在执行的任务；检查已有结果后，明确发送下一条消息可以创建新环境，继续使用已保存的会话和工作文件。

## 服务重启后会自动继续吗

已保存的对话和文件可以重新打开。重启前尚未完成的消息会标记为中断，平台不会自动重发。先检查已经产生的文件和外部操作，再发送继续执行的要求，避免重复操作。
