# V4网页客户端 · 页面与交互设计

2026-10-22。macOS风格、企业个人工作台。正式原型位于`src/clients/web/prototype/`，浏览入口为`index.html`。本阶段仅设计与本地模拟，不连接真实服务或模型，不改变V3实现。

## 页面定位

面向在企业里处理开发、资料整理与验证任务的成员。主任务是找到自己的会话、提出明确任务、持续查看过程，并理解任务和环境的状态。不是组织管理后台，不使用没有实际数据来源的总览图表。

工作台采用三栏：228px会话导航、可伸缩对话区、265px详情区。顶栏放产品与原型标识；会话标题、当前任务状态和关闭环境留在工作上下文内。全部会话使用表格，便于比较状态与查找工作。

## 视觉约定

| 项目 | 约定 |
| --- | --- |
| 主文字 | #20242c，正文13.5px；标题20px |
| 次级文字 | #838995，状态与辅助信息通常10–12px |
| 表面 | 白色内容区，#f5f6f8侧栏，#e6e8ed细分隔 |
| 强调色 | #396be9，主要用于发送和当前选择 |
| 状态色 | #28866d正常、#ab791f待确认、#c85252失败，均同时有文字 |
| 字体 | SF Pro/PingFang系统栈；编号及代码使用SF Mono/Consolas |
| 控件 | 6–11px圆角、轻边框与轻阴影；不模拟浏览器里的原生红黄绿窗控 |
| 特征 | 右侧把“当前任务”与“工作环境”分区呈现，让停止本轮与关闭环境在视觉上也保持不同范围 |

mac风格主要体现在字体、密度、表面层次和快捷键；企业系统感来自稳定导航、信息分层、可追溯进度及明确操作范围，不来自堆砌管理菜单。

## 关键流程与V3映射

| 用户动作 | 页面行为 | 正式接入对应 |
| --- | --- | --- |
| 新建会话 | 名称和空白/示例模板，创建后进入空态 | POST /sessions；UUID由服务生成 |
| 找/切换会话 | 左侧最近会话、标题搜索；全部会话表格 | GET /sessions；客户端搜索已加载会话，不承诺全文搜索 |
| 连续发送 | 多行输入，Cmd/Ctrl+Enter；忙时留草稿、不排队 | POST messages，保留clientMessageId到接收确定 |
| 看回答和工具 | 流式回答、可折叠工具调用记录 | SSE与消息历史；工具目前仅有名称/已发起，不伪造单工具完成、参数或耗时 |
| 停止本轮 | 正在停止→确认停止，通常保留环境 | 按捕获的messageId发cancel，等待最终事件 |
| 关闭环境 | 明确会话名称及停止全部进程的说明→关闭中→已关闭 | close携带所见lastMessageId；202不是已关闭 |
| 连接断开 | 保留上次记录、禁发/停/关，允许写草稿 | 不发cancel；重连查询状态和按eventId补看 |
| 状态待确认 | 保留历史，阻止发送；重新查询不等于修复或已停止 | GET session读取最新事实；维护者协调环境，网页不能伪造恢复 |
| 本轮失败 | 已保存内容可读，新任务必须由用户明确发送 | 终态失败不自动重试，不回放原副作用 |

V3没有网页登录会话或浏览器凭证安全存储方案。本原型不设置“输入密钥并存localStorage”的临时登录方式。正式接入前单列同源服务与身份方案；企业SSO、角色和团队空间管理属于后续范围。

## 状态与交互约定

- 三个维度分开：查看连接、当前消息、工作环境。断线不是失败；消息完成不等于容器关闭。
- 停止按钮只针对本轮，不撤销文件修改；环境关闭停止容器内全部进程。确认文案写明作用范围。
- 新会话还没有创建环境；发送首条消息才准备。回收后继续发送会恢复对话，不承诺恢复进程内存。
- 草稿按会话隔离；切换A→B→A不覆盖。原型仅保存于当前页面内存，刷新会重置；正式版需明确浏览器本地持久化方案。
- 演示任务按创建时的会话ID运行，切换不会把进度、停止或关闭投到新会话。其他会话更新不重绘当前正文、不改变阅读位置。
- 原型断线时冻结展示快照，演示执行继续；重连后补齐展示。全部数据为合成，不表示服务或原生执行经过验收。
- 输入框支持多行；空白不能发送。连接/执行不允许发送时可继续写草稿。
- 快捷键：Cmd/Ctrl+K定位搜索，Cmd/Ctrl+N新建，Cmd/Ctrl+Enter发送。弹窗可Escape关闭，焦点返回入口。

## 窗口适配

1440px桌面验证三栏；1180px以内详情收成抽屉；760px以内左侧导航收起，由按钮展开。对话与侧栏独立滚动，输入框保持可见。375px窄窗口检查标题、操作与输入区，无页面横向溢出。

## 本轮边界

没有文件树/上传下载、模型切换、审批、组织管理或费用页面，因为现有V3没有相应网页契约。先把会话这条链路做清楚。原型只使用原生HTML/CSS/JS，不增加生产依赖。

已选择的后续验收优先级仍为真实网关端到端验收；本设计不替代该验收。用户评审页面后再按选定布局接入V3，保留原有幂等、事件游标和停止语义。
