# 工作区与文件

每个会话有独立工作区，用来保存上传资料和 Agent 生成的文件。

## 上传资料

先打开已有会话。首次使用时，在首页选择「对话」并发送一条消息进入会话，等当前任务结束后再上传；首页暂不提供文件上传入口。

1. 在输入框旁点「上传资料」，或在右侧「工作区 → 文件」点「上传文件」。
2. 选择一个或多个文件，等待上传完成。
3. 在右侧文件区的「上传记录」中点「插入消息」带上文件路径，再说明处理要求并发送。

上传本身不会启动任务。任务执行期间不能上传新文件，等当前任务结束或停止后再上传。

上传内容是工作副本，Agent 可以修改它。需要保留原件时，请在自己的电脑另存一份。

## 查看与下载

在文件列表中按目录浏览，点击文本文件预览，使用下载按钮保存到电脑。HTML 和 SVG 显示源代码；PDF、Office 和 ZIP 可以上传下载，文件页不会自动转换或运行它们。

Agent 处理某种文件的能力取决于所选模型和已安装工具。上传成功不代表内容已经解析。

文件变化后重新获取列表和预览。下载最终成果前，先等任务结束；需要停止环境中的所有写入进程时，使用「关闭工作环境」。

## 文件限制

| 项目 | 当前限制 |
| --- | --- |
| 单文件上传 | 20 MiB |
| 文本预览 | 前 256 KiB |
| 单文件下载 | 100 MiB |
| 单目录列表 | 最多 1,000 项 |

当前不支持目录上传、自动解压、网页直接编辑和目录打包下载。需要解压或打包时，可以在任务中提出要求，再下载生成的文件。

## 文件会保留多久

关页面、停止任务或关闭环境都会保留工作区文件。永久删除对话会清理这些文件。服务磁盘的备份由部署者负责。
