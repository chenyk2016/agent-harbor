专家把角色说明、工作方法和技能组合保存起来，方便反复使用。例如，“活动数据分析师”可以固定分析步骤和报告格式，每次只需上传新的报名表。

Harbor 支持直接创建专家，也支持导入 WorkBuddy 格式的 ZIP 包。专家用于新建一段采用固定配置的会话；单独复用某项处理方法，见[技能](skills.md)。

## 创建自己的专家

1. 打开「资料库 → 专家」，点击「创建专家」。
2. 填写专家名称、简介和完整的 Markdown 说明。写清负责什么、怎么处理资料、结果要包含什么。
3. 点击「保存专家」，进入详情。需要修改时，可以编辑专家包文件并「保存包新版本」。
4. 选择模型，点击「召唤专家」，进入会话后发送第一条任务消息。

例如，专家名称填写“活动数据分析师”，完整说明可以写成：

```markdown
你帮助活动组织者分析报名数据。

先查看用户上传的表头，确认统计口径，指出缺失值和重复记录。
按用户指定的渠道、日期或人群汇总，不推测表中没有的信息。
输出主要发现、数据限制和后续建议，并生成可下载的汇总 CSV。
```

进入会话后上传报名 CSV，再发送：

> 请按渠道汇总报名人数，说明哪些记录无法归类，并生成汇总文件。

检查对话中的分析过程和工作区文件，确认专家遵循了预期方法。

## 导入 WorkBuddy 专家包

1. 在专家列表点击「导入 WorkBuddy」，选择原 ZIP 包。
2. 打开详情，查看完整 Agent 说明、包内技能和其他文件，留意缺少依赖或能力的提示。
3. 如果声明了外部服务，先按下一节完成连接。
4. 选择模型，点击「召唤专家」。需要的包内技能会先准备，完成后自动进入会话；也可以先点击「准备技能」查看准备情况。
5. 进入会话后发送任务消息。保存和技能准备本身不会调用模型，实际任务会使用所选模型的额度。

导入会创建一位新专家。后续修改请在详情编辑文件并点击「保存包新版本」。未修改的文件和图片等资源会保留；使用「下载原包」可以导出所选版本的包。

包内技能只用于这个专家，不会自动打开个人技能库中的默认开关。使用新版本时，请从专家详情重新召唤；已有会话保持原来的专家和技能版本。

## 连接外部服务与在线资料

在专家详情的「网络与外部连接」中逐项检查：

| 页面显示 | 操作 |
| --- | --- |
| 需要读取网页或下载资料 | 填写允许访问的域名，点击「保存网络范围」；多个域名用逗号分隔，下一轮生效 |
| 要求 Token 或其他参数 | 填写对应字段，点击「连接」 |
| 要求 OAuth | 点击「连接并授权」，再前往服务商完成授权 |
| 尚未接入的 WorkBuddy 连接器 | 联系管理员接入相应服务，不能跳过依赖直接使用 |

确认所需服务都显示「已连接」后再召唤专家。授权属于当前用户，不随专家 ZIP 导出。请在连接表单里填写凭据，不要写入专家说明或包文件。

网络范围只对这个专家的工作环境生效，仍受管理员规则限制。允许域名只解决访问权限；对方要求登录、链接失效或服务不可用时，仍可能无法获取资料。

## 管理员接入连接器

WorkBuddy 专家包不包含用户在 WorkBuddy 中的登录状态，也不能直接取得其私有连接器。需要提供可用的远程 MCP 服务，并在数据目录 `AH_DATA_DIR` 下的 `connector-providers.json` 中按连接器 ID 配置，例如：

```json
{
  "your-connector-id": {
    "type": "http",
    "url": "https://your-service.example/mcp",
    "x-workbuddy": {
      "displayName": { "zh": "企业连接器" },
      "auth": { "type": "oauth" }
    }
  }
}
```

远程 MCP 目标还需符合平台允许的来源配置，见 [MCP 工具](mcp.md#连接远程服务)。OAuth 服务须支持所需的客户端注册和授权流程，回调地址为 `AH_PUBLIC_ORIGIN` 对应地址下的 `/api/expert-oauth/callback`。接入后用实际账号授权并测试所需工具，不能只凭服务名称判断能力一致。

## 使用限制

- 专家包可以保存完整说明、技能和资源；格式可导入不代表所有外部服务及任务效果都与 WorkBuddy 相同。
- 专家团的成员共享同一段会话的工作环境，不是彼此独立的数据空间。
- 包中声明工具不会增加平台权限。当前没有可用的原生 WebSearch 服务；依赖该服务的专家需要另接可用工具。
- 包中未声明的 Python/Node.js 依赖不会被自动推测安装，在线资料也不会自动变成离线资源。
- 专家会话目前只接受远程 HTTP 工具服务。包若仅提供 SSE 或本地 stdio 配置，需要先提供可用的 HTTP 服务；不会直接在宿主机器执行包内命令。
- 外部服务的权限、费用和可用性由对应服务决定。授权到期后可能需要重新连接；不要反复提交结果不明的外部写操作。
