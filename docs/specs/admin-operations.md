# 管理后台运营能力

日期：2026-11-04。用户授权设计及实现。以普通对话的运行、用户、费用和配置管理为范围。

## 工作流及验收

1. 修正总览部分失败时的健康空态；正常停用账号不列异常；预占模式说明来自服务端；扣费队列按全量数据搜索、筛选、分页；模型审计可展开前后值。
2. 运行状态：执行服务、数据库、LiteLLM存活及用量同步最近成功时间；指标只来自实际记录，不主动调用付费模型。站内异常持久化，支持认领、备注、确认恢复；条件仍成立时不能关闭，已关闭问题复发时重新打开。
3. 请求查询：钱包请求全状态及会话/轮次元数据查询，包含模型、版本、起止、用量、预占/扣费/免收与call ID。核对抽屉可查看网关观察和价格快照。默认不暴露提示词、回答、命令或工具正文。旧记录无法证明轮次归属时明确未知。
4. 用户任务与资源：分页展示会话、活动消息、环境状态、停止结果；实际工作文件空间显式按需测量，禁止跟随符号链接，不能把限额当实际占用。
5. 用量分析：可选日期/用户/模型，人民币扣费、预占、免收与USD观察分别汇总；未知用量/价格单列。耗时统计为模型转发实际计时或明确标注的历史请求至结算时间，不能称为供应商纯推理耗时。
6. 统一审计：记录管理员写操作的操作者、目标、脱敏前态、请求变更、结果及时间；模型历史审计可查。先持久记录意图再执行；若最终记录未确认则保留unconfirmed，不冒充原子业务账本。覆盖用户、额度、Plus、赠送、核对、配置。凭据和任意正文不入审计。
7. 变更预览：供应商地址、模型当前版本、售价/成本、使用范围修改前显示影响及生效规则；提交包含预览状态校验，已变化则要求重新预览。旧版本仍由已有CAS指针回切。
8. 历史查询与导出：请求、人民币流水、审计均支持服务端日期/用户/模型适用筛选和分页；CSV只含白名单字段、处理公式注入，有明确条数上限及partial提示。

## 实现边界

沿用单Node进程、PG、现有管理员身份；新增`admin`模块及受控迁移，不引入外部通知、支付、组织审批或第三方追踪服务。原生工具循环/取消锁保持，新增工具结束元数据通过SDK Hook采集；模型调用只能证明到会话时不按时间猜messageId。

保留旧钱包接口兼容性。管理接口全部在身份、管理员检查和CSRF之后；静态路由显式加入白名单。浏览器新页有加载、错误、空态、筛选和窄屏布局。

## 验证

隔离PG覆盖权限、全量搜索、异常恢复、审计脱敏、预览过期、分页导出、未知成本、历史无轮次和资源测量。执行类型检查、全量测试、公开审计；隔离浏览器验证所有新页及旧管理流程。正式部署先备份、确认无活动模型请求、执行新增迁移再启动；不调用真实供应商作为健康探针。

## 本地落地与恢复

构建新增覆盖镜像：`docker build --pull=false -f infra/Dockerfile.admin-operations -t agent-harbor:admin-operations-v28 .`，继承既有MCP/skills基线且不覆盖其标签。新会话通过`AH_SKILL_IMAGE`固定新镜像；已有会话保留原capabilitySnapshot/imageId，旧AH_IMAGE保持。切换前为当前启用技能准备对应新镜像构建；否则默认技能选择会返回未就绪。实际Docker/SDK验证入口`node tests/admin-runner-verification.mjs`，本地确定性模型、零真实调用。

运行服务升级：停止接收前确认无活动消息，私有备份控制库/服务目录/环境，迁移0015再启动。比较前后余额、流水、请求和旧会话快照；恢复旧服务代码/环境不需删除新增表列，不在运行中重写旧会话镜像身份。正式备份恢复及真实供应商验收仍须独立演练。
