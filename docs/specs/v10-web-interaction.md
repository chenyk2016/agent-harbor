# V10 前端交互与界面重构 · 静态稿

- 日期：2026-10-28
- 状态：待确认（仅静态稿，未改 React / 后端）
- 产物：`apps/web/redesign/v10.html`（自包含单文件，离线可开）
- 基线：V9 界面已落地（三栏骨架 + 浅色 token），本稿在其上做交互与信息架构升级
- 后续：V11 已移除新建会话弹窗、首页自动续接和会话页的创建空态，改为总入口与对话/应用分流，见 `v11-unified-entry.md`。

## 背景

V9 解决了视觉统一和三栏骨架，但仍是「后台式」的：一级导航混放会话与 5 个管理入口；会话列表平铺；工具调用只显示次数；输入区固定三行；右栏是属性罗列。对标 Codex、Claude Code、豆包、WorkBuddy 后，差距集中在两处：**任务过程不可审阅**、**开始任务摩擦大**。

本次目标是产出一版可点击评审的静态稿，确认后再进入 React 实现。

## 对标参考

| 产品 | 借鉴的交互 | 没有照搬的部分 |
| --- | --- | --- |
| Codex | 以任务/运行为中心、工具步骤可见、输入区集中环境与模型、克制的单色外壳 | 终端式全屏、面向单机的本地路径心智 |
| Claude / Claude Code | 执行计划、可折叠工具调用、安静排版、文件/产物面板 | Artifacts 画廊、面向个人订阅的模型切换 |
| WorkBuddy | 专家角色卡、技能包、从角色直接开始会话 | 以「角色扮演」为主的首页叙事 |
| 豆包 | 低摩擦空态、大输入区、建议 chips、友好文案 | 语音、娱乐化表情与消费级视觉 |
| ChatGPT | 会话置顶与时间分组、⌘K 命令面板、hover 行操作 | Projects、Canvas、GPTs 商店 |

取共同点：**过程可见、开始成本低、会话与资料库分开**；保留 Agent Harbor 的多用户隔离、环境和状态语义。

## 评审方式

- 直接双击 `apps/web/redesign/v10.html`，无需构建或联网。
- 右下角「演示」可切换页面、6 种会话状态和主题；该控制器不会进入正式版。
- 主要交互：⌘K 命令面板、新建会话、工具步骤展开、右栏三个标签页、文件预览、Enter 发送（演示）。

## 目标

1. **重排信息架构**：一级导航收敛为会话 / 应用 / 资料库 / 设置四项；技能、专家、MCP、模型归入资料库二级导航。
2. **工作过程可审阅**：每轮展示执行计划、工具步骤、命令与输出、耗时；右栏可查看本轮触及的文件。
3. **输入区成为主入口**：自适应高度、附件 chip、拖拽提示、专家/模型/环境同区、Enter 发送。
4. **右栏改为工作区**：概览 / 文件 / 动态三页，文本文件可在栏内预览。
5. **视觉降噪并提供暗色**：暖中性底色、少边框、清晰层级；浅色与暗色都由同一套 token 派生。
6. **保留全部现有能力与硬约束**：会话隔离、状态语义、停止本轮与关闭环境的区分、草稿保留、错误文案。

## 不做什么

- 不改 `apps/web/src/**`、`src/service/**` 与任何接口契约。
- 不引入框架、构建工具、CDN、外部字体或图片；单文件内联，离线可开。
- 不承诺后端当前没有的能力：文件 diff、消息编辑、跨会话全文搜索、工具级实时输出流。静态稿中出现的相关位置在本文「依赖」一节标注。
- 演示控制器（右下角）只用于评审，不进入正式版。
- 不写 localStorage、不接网络。

## 设计决策

### 1. 布局与断点

| 宽度 | 布局 |
| --- | --- |
| ≥ 1180px | 图标栏 64 + 会话/二级导航 292 + 主区自适应 + 工作区 372 |
| 900–1180px | 工作区改为右侧抽屉，主区占满 |
| < 900px | 会话列表改为左侧抽屉，主区占满 |
| < 640px | 图标栏 56，内容边距收到 16px，单列 |

应用画廊与应用详情不显示会话列；设置不显示工作区。

### 2. 一级导航

- **会话**：会话列表（置顶 / 今天 / 昨天 / 更早，hover 出现 ⋯ 菜单）。
- **应用**：应用画廊 + 应用详情工作台。
- **资料库**：二级导航为技能 / 专家 / MCP 连接 / 模型与网关。
- **设置**：二级导航为账户与用量 / 访问密钥 / 外观 / 关于。
- 底部保留用户头像与「⌘K 搜索」入口。

理由：ChatGPT、Claude、Codex 都把「会话」与「资料库」分开；管理型入口不应和会话抢同一列。

### 3. 会话状态语言

面向用户的状态收敛为 6 种，技术状态保留在右栏：

| 现有 `Message["status"]` | 界面文案 |
| --- | --- |
| accepted / running / finalizing | 正在执行 |
| succeeded | 已完成 |
| cancelled | 已停止 |
| failed | 执行失败 |
| interrupted | 执行中断 |
| reconciling | 结果待确认 |

断线与提交待确认单独用提示条表达，不混进状态胶囊。

### 4. 输入区行为（需确认）

- **Enter 发送，Shift + Enter 换行**（主流 AI 产品默认）；保留 ⌘/Ctrl + Enter 作为兼容快捷键。
- 附件在输入框上方以 chip 回显，可逐个移除。
- 执行中发送按钮替换为「停止本轮」，并显示已用时间。
- 模型、专家、环境状态放在同一行，不额外占一行说明文字。
- 上下文用量用环形指示，不显示精确 token 数字。

### 5. 视觉

- 底色从冷灰改为暖中性（`#F6F5F2`），主色保留 Harbor 蓝（`#2E5AE0`），成功/警告/危险独立语义色。
- 正文 15px / 行高 1.75；会话列表 13.5px；元信息 11.5–12px。
- 边框承担主要分隔，阴影只用于浮层；圆角 8/10/14/18。
- 暗色与浅色共用 token，`prefers-color-scheme` 与手动切换都生效。
- `muted` 提升到 `#746E66`，白底对比度 ≥ 4.5:1。

### 6. 键盘

`⌘/Ctrl + K` 命令面板，`⌘/Ctrl + N` 新建会话，`Esc` 关闭浮层，`Enter` 发送。

## 页面清单（静态稿）

1. 会话工作台：空态、执行中、已完成、失败、结果待确认、断线六种状态。
2. 应用画廊：一句话创建区 + 应用卡片（草稿 / 构建中 / 已发布）。
3. 应用详情：左侧对话，右侧预览 / 版本 / 数据 / 发布。
4. 资料库 · 技能：分组卡片、启停、版本、来源。
5. 资料库 · 专家：角色卡、技能依赖、直接开始会话。
6. 资料库 · MCP 连接：连接列表 + 编辑表单（含密钥仅写入）。
7. 资料库 · 模型与网关：余额、可用模型、价格与权限。
8. 设置 · 账户与用量：额度、token、费用、钱包。
9. 设置 · 访问密钥：列表、到期、吊销、新建。
10. 设置 · 外观：浅色 / 暗色 / 跟随系统。
11. 设置 · 关于。
12. 登录页。
13. 命令面板（⌘K）。
14. 新建会话浮层。

## 依赖与风险

| 界面元素 | 现在是否可得 | 说明 |
| --- | --- | --- |
| 计划 / 工具步骤 / 工具名 | 可得 | 现有流事件已提供工具调用记录，需补参数与耗时字段 |
| 命令输出 | 需补充 | 现有事件只有工具名；实时输出需 runner 侧上报或落盘摘要 |
| 本轮触及的文件 | 可推导 | 从 Edit / Write 工具事件提取路径，不依赖 diff |
| 文件预览 | 可得 | 现有文件下载接口可支持文本/代码只读预览；二进制仍走下载 |
| 上下文用量 | 需补充 | 需网关回传当前会话 token 占比 |
| 暗色 | 可实现 | Chakra theme 增加语义 token 与 `color-mode` 持久化 |
| Enter 发送 | 行为变更 | 需确认，避免影响现有用户习惯 |

## 验收标准（静态稿）

- 双击 `apps/web/redesign/v10.html` 即渲染，无外部请求。
- 4 个一级页面、11 个二级视图可点击切换。
- 6 种会话状态可切换，状态色与文字并重。
- 浅色 / 暗色可切换；两种主题下文字对比度 ≥ 4.5:1。
- 1440 / 1180 / 900 / 375 宽度下无横向溢出。
- 命令面板可打开、过滤、跳转。
