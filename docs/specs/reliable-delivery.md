# 可靠安装与完整验收

范围：受信小团队、单机Linux宿主服务、Compose PostgreSQL/LiteLLM，保留原生SDK/锁/取消，应用默认关闭。Mac为开发验证；不声称未测试Linux目标已经准入。统一入口`node dist/src/clients/ops/main.js`，仓库用`npm run harbor --`。

命令：configure首次生成私有环境；doctor分层检查宿主/数据库/镜像/沙箱；install启动受控依赖、迁移、检查；init在停服锁下初始化管理员和模型；status/verify免费；acceptance启动独立实例执行确定性或显式live任务；backup/restore仅停服、有归属、空目标恢复；service生成systemd文件；monitor轮询、状态变化通知；package生成固定版本发布包。

安全：凭据不输出报告，明文首次管理员密钥只写专用0600文件且不回显；初始化重复运行不生成/恢复已撤销密钥。数据根必须专用绝对路径，服务根锁贯穿所有离线变更。备份保留SQL dump、网关dump、完整文件树及环境，含敏感信息且权限0700/0600；恢复必须新空目录和空数据库，不自动覆盖或删除运行数据；校验内容摘要及版本。不能把可读备份当恢复成功。

验收隔离：独立测试库/数据根/端口/账号与容器标签；真实模型仅显式选项+明确预算才执行，次数/超时有上界，无自动业务重试；预算是限制与观察口径，不宣称供应商绝对封顶。默认仅免费检查；标准任务由独立校验器检查CSV金额与代码测试，不采纳Agent自报。HTTP身份与真实浏览器检查分别记录。

发布：自有编译代码、迁移、网页、模板、必要infra、锁文件与清单；依赖安装来自官方注册表，运行SDK受自身条款。公开包必须通过已有公开历史审计；本机验证包明确标local-only，不可冒充公开审查通过。服务systemd仅生成文件，不自动改机器设置；升级显式备份再迁移，不自动改变既有会话镜像。通知默认本地记录，远程webhook只能显式配置，最小元数据，不含正文/凭据。
