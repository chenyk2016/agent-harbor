# V9 前端界面重设计 · 静态 UI 规格

- 日期：2026-10-26
- 状态：待确认
- 范围：仅静态 UI 稿（纯 HTML），不接后端、不改 React 源码

## 背景

当前 `apps/web` 是 React + Chakra UI 的浅蓝企业后台风格：左侧会话栏 + 顶栏 + 中间内容，
会话列表是普通表格，聊天是简单气泡，技能/专家/MCP/设置是普通卡片和表单。
状态信息（任务是否在跑、环境是否可用、连接是否正常）主要靠小灰字表达，可读性和可用性都不足。

用户要求重新设计一版界面，先以纯 HTML 输出静态 UI 供评审，再据此替换真实前端。

## 目标

1. 建立一套统一、克制的浅色设计系统，摆脱"浅蓝企业后台"观感，保留 Agent Harbor / 锚的品牌识别。
2. 把「任务状态 / 环境状态 / 连接状态」做成一眼可辨的第一级信息。
3. 覆盖全部页面与关键状态（空态 / 执行中 / 完成 / 失败 / 断线），可点击走通主要流程。
4. 静态稿结构直接对应现有 React 路由与数据类型，后续可无痛替换。

## 产物与落点

- 新增 `apps/web/redesign/index.html`：自包含单文件（内联 CSS + 极少量原生 JS 仅做页面切换与状态演示）。无框架、无构建、无外部依赖，双击即可打开。
- 新增本规格 `docs/specs/v9-web-redesign.md`。
- 不改动 `apps/web/src/**`、`src/service/**` 及任何后端/执行逻辑。

## 视觉设计系统（浅色效率工具风）

### 颜色 token（CSS 变量）

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--bg` | `#F5F6F8` | 应用画布 |
| `--surface` | `#FFFFFF` | 卡片/面板 |
| `--surface-hover` | `#F8F9FB` | 悬停 |
| `--surface-sunken` | `#F1F3F6` | 输入框/代码底 |
| `--border` | `#E7E9EE` | 常规描边 |
| `--border-strong` | `#D3D8E0` | 强调描边 |
| `--ink` | `#1A2130` | 正文 |
| `--ink-2` | `#4A5468` | 次级文字 |
| `--muted` | `#8A93A6` | 辅助/占位 |
| `--brand` | `#3B6CF6` | 主强调（发送、选中、链接） |
| `--brand-strong` | `#2E56D8` | 悬停/按下 |
| `--brand-tint` | `#EEF3FF` | 选中背景/淡底 |
| `--beacon` | `#0E9F8E` | 港口信标色（成功/环境正常） |
| `--amber` | `#D97706` | 待确认/警告 |
| `--red` | `#E5484D` | 失败/危险/关闭 |

状态色同时配文字与图标，不单独依赖颜色（色盲可读）。

### 字体与字号

- 正文：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`
- 等宽：`"SF Mono", "JetBrains Mono", Menlo, Consolas, monospace`（编号、代码、路径、会话 ID）
- 基准 16px；标题 20–22px，正文 15–16px，辅助 13–14px，微标签 12px，任何正文不低于 16px。

### 间距 / 圆角 / 阴影

- 4px 网格：`4 8 12 16 20 24 32 40`。
- 圆角：控件 8px、卡片 12px、弹窗/大容器 16px。
- 阴影：`sm 0 1px 2px rgba(16,24,40,.04)`、`md 0 4px 12px rgba(16,24,40,.06)`、`lg 0 12px 32px rgba(16,24,40,.10)`。

### 图标

内联 SVG（线性描边，2px，继承当前文字色），延续现有 Lucide 语义：锚形 Logo、加号、搜索、消息、布局、专家、MCP、设置、上传、文件夹、下载、终端、停止、关闭电源、复制、刷新、登出等。

## 布局与页面结构

### 全局外壳（登录后）

三栏，左侧导航 268px，中间内容自适应，右侧上下文面板 320px（仅会话工作台显示）。

- **左导航**：品牌 Logo + 名称 → 新建会话（主按钮）→ 搜索会话 → 一级导航（会话工作台 / 全部会话 / 我的技能 / 专家 / MCP 连接）→ 最近会话列表（状态圆点 + 标题 + 状态文字）→ 底部（连接状态 + 用户头像 + 登出）。
- **顶栏**：页面标题 + 一句副标题；右侧当前会话状态胶囊 + 图标按钮（文件 / 详情 / 使用说明）。
- **窄屏**：< 992px 导航收为抽屉，< 1200px 右侧上下文面板收为抽屉；375px 无横向溢出。

### 页面清单

1. **登录**：居中卡片，Logo + 欢迎语 + 统一身份登录按钮 + 开发访问密钥输入（密码框）+ 登录按钮 + 底部说明。
2. **会话工作台**（核心，三栏）：
   - 中间：对话流（用户消息右对齐气泡、Agent 回答左对齐带 Logo、可折叠工具调用记录、复制按钮、状态标签）+ 底部输入区（多行输入 + 上传 + ⌘/Ctrl+Enter 提示 + 发送/停止按钮 + 提交待确认/错误提示条）+ 空态引导（三张建议卡片 / 新建会话按钮）。
   - 右侧上下文面板，两个标签页：
     - **详情**：当前任务状态胶囊 → 工作环境（状态 + 关闭环境按钮）→ 专家快照 → 技能快照 → 最近进度 → 会话信息（创建时间 + 会话 ID）。
     - **文件**：面包屑 `/workspace/…` → 上一级/刷新 → 文件列表（目录/文件图标 + 名称 + 大小）。
3. **全部会话**：搜索 + 计数 + 新建按钮 + 卡片式列表（标题、当前任务状态胶囊、环境、最近更新时间），替代原来的普通表格。
4. **我的技能**：分组（用户自定义 / 平台内置）→ 搜索 + 导入/新建按钮 → 卡片网格（名称、描述、版本、启用开关、安装状态徽标）。
5. **专家**：搜索 + 分类筛选 + 导入/创建按钮 → 分组（我的专家 / 平台内置）→ 卡片网格（头像、名称、职业、描述、标签）。
6. **MCP 连接**：左侧连接列表（名称 + 远程/本地 + 启用状态）+ 右侧编辑表单（名称、类型、URL/模板、允许工具、密钥、启用开关、保存）。
7. **用量与密钥**：用户信息 → 四格额度（会话/任务/环境/文件，`已用 / 上限`）→ 估算费用卡片（金额 + token 统计）→ CLI 访问密钥列表 + 新建密钥 + 仅显示一次的明文。

### 关键状态（会话工作台演示）

- **空态**：欢迎语 + 三张建议卡片。
- **执行中**：状态胶囊"正在执行"（脉冲动画）、停止按钮可用、回答流式光标。
- **已完成**：绿色"本轮已结束"、环境"环境可用"。
- **失败**：红色"执行失败" + 说明"本轮未正常完成"。
- **断线**：顶部黄色提示条"正在连接并核对状态" + 重新连接按钮，输入可写草稿、禁发。
- **提交待确认**：输入区上方黄色条 + "核对并重试"。

静态稿内用一个小型"状态演示"切换器在这些状态间切换，方便评审。

## 交互约定

- 快捷键提示：`⌘/Ctrl+K` 搜索、`⌘/Ctrl+N` 新建、`⌘/Ctrl+Enter` 发送、普通 Enter 换行。
- 静态稿中的页面切换、标签页切换、弹窗开关用最小原生 JS 实现；不接网络、不持久化。
- 弹窗（新建会话 / 关闭环境 / 使用说明）以遮罩层演示，Escape 可关。

## 不做什么

- 不接真实接口、不加载真实数据、不使用模型、不写 localStorage。
- 不改动 React 源码、后端、执行引擎、Docker、数据库。
- 不引入任何框架、构建工具、外部 CDN 资源、字体或图片（全部内联，离线可开）。
- 不做暗色主题（本次按已确认的浅色方向单主题输出）。

## 验收标准

- `apps/web/redesign/index.html` 双击打开即渲染，7 个页面可点击切换。
- 会话工作台三栏完整：导航 / 对话（含工具调用与流式演示）/ 右侧详情+文件。
- 5 种关键状态可切换演示，状态色与文字并重。
- 375px 窄屏无横向溢出；无控制台报错（仅静态稿自身的 JS）。
- 视觉风格与已确认方向一致：浅色、克制、统一 token、无零散样式。

## 第二阶段：React 实现方案（2026-10-26）

- 技术方向（已确认）：**保留 Chakra UI**，重做主题与视图结构；`state/` 状态层与 `BrowserApi` 完全不动。
- 依赖：不增删（@chakra-ui/react、@emotion/*、framer-motion、lucide-react、react-markdown、remark-gfm、react-router 全保留）。
- 改动清单：
  - `app/theme.ts`：按静态稿 token 重写（语义色、15px 基准、38px 控件、圆角/阴影、Button/Input/Modal 等组件样式）。
  - `app/styles.css`：保留 Markdown 阅读样式并刷新为 15px 基准。
  - `shared/ui.tsx`：`Pill` / `Status` / `Mark` / `Hint` 等展示组件重做，保留 `statuses` / `environments` / `date` / `bytes` 导出。
  - `Sidebar.tsx`：去掉「会话工作台 / 全部会话」，改为「会话历史 + 技能/专家/MCP + 用量密钥」。
  - `Workbench.tsx`：三栏（导航 / 主区 / 常驻右栏），顶栏只留标题 + 使用说明。
  - `Chat.tsx`：消息、工具调用、输入区、各状态按静态稿。
  - `Details.tsx` / `Files.tsx`：右栏「详情 / 文件」两个标签页。
  - 删除 `SessionsPage.tsx`；`App.tsx` / `route-pages.tsx` 去掉 `/sessions` 列表路由。
  - `Login.tsx` / `Account.tsx` / `Skills*` / `Experts*` / `McpPage.tsx`：按静态稿重排视觉。
- 不做什么：不改状态层、不改接口、不引入新依赖、不做暗色主题、不把原型状态演示器带进真实应用。
- 验收：`npm run check` 与 `npm run build:web` 通过；页面结构与静态稿一致；现有 web 测试不回归。
