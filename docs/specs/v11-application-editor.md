## 一、原始要求

重做应用编辑页（`/applications/:id`）的布局、视觉和信息层级，解决「丑」和「乱」，整体参考给定的两张应用工作台截图。

| 改完要能验收 | 不能只靠类型检查冒充界面完成 | 给出宽度、键盘、空态、失败态验收项；无浏览器实测时明确标注 |

## 四、目标

1. **顶部只做模式切换**：标题、状态、工作台/预览、上下文工具栏、发布，一行解决。
2. **对话常驻**：桌面端编辑时始终能继续对话，不再和预览互相抢位置。
3. **工作台有稳定导航**：8 个功能变成 7 个分区 + 内容区，选中态清晰。
4. **预览像真实页面**：地址栏控制，画布居中，桌面/手机/专注预览。
5. **整体降噪**：正常状态不占空间；统一卡片、字号、间距、空态和加载态。
6. **保留全部能力与语义**：不改接口、轮询、发布/回滚/下线、预览回收规则。

### 5.2 顶部工具栏（52px）

左侧：

1. 应用标记：40px 圆角方块，`Mark` 同款渐变底 + 应用名首字；无图时不使用随机缩略图。
2. 应用名称，14.5px / 650，单行省略。
3. 名称旁铅笔图标，`aria-label="修改应用名称"`，点击切到「工作台 → 设置」并聚焦名称输入框。
4. 应用状态胶囊，使用 `shared/ui.tsx` 的 `Pill`，映射见 5.2.1。

中部：

- 分段切换「工作台 / 预览」，`role="tablist"`，当前项白底 + `shadow-1`，容器 `sunken`，高 32px。
- 预览模式下，切换右侧出现上下文工具栏：只读地址栏（预览 URL 或「预览准备完成后显示访问地址」）、刷新、桌面/手机、新窗口、专注预览。
- 工作台模式下，上下文工具栏隐藏，右侧留空。

右侧：

- 源码版本胶囊 `v3`，Tooltip「当前源码版本」；生成中显示脉冲小点。版本号只在这里出现一次。
- 「记录」图标按钮（`History`），切到「工作台 → 操作记录」。
- 「发布」主按钮 + 右侧下拉箭头，拆成 split button：
  - 主按钮：发布当前版本，文案 `发布 v3`；预览未匹配时禁用并 Tooltip「需先准备 v3 的预览」。
  - 菜单：打开线上地址、复制线上地址、下线应用（未发布时禁用，danger 样式）。
- 关闭 `✕`，`aria-label="返回应用列表"`，行为等同现有返回。

### 5.3 状态提示条（取代常驻横幅）

默认不渲染。只有以下情况出现，高度 ≤ 44px，位于顶栏下方、横跨对话和工作区：

| 条件 | 内容 | 动作 |
| --- | --- | --- |
| 源码操作进行中（create / generate / restore / snapshot） | 旋转图标 + `phases[phase]`（如「正在生成应用」） | 无；停止本轮在输入区 |
| 最近一次生成失败 / 取消 / 待核对 | 一句话原因（沿用 `operationError`） | 「查看原因」「继续修改」；待核对时「核对运行状态」 |
| 预览构建失败 / 取消 / 待核对 | 一句话原因 | 「查看原因」「重试预览」 |
| 其他 | 不渲染 | — |

提示条使用 `role="status"`、`aria-live="polite"`；进行中用 `brand.50`，失败用 `warnTint`，不使用整块深色警告。

### 5.5 预览模式

**地址栏**（顶部工具栏内，唯一控制区）：

- 只读地址：就绪时显示预览 URL，否则显示占位文案；过长省略，`font-family: mono`，11px。
- 刷新（`RefreshCw`）。
- 桌面 / 手机切换（`Monitor` / `Smartphone`），手机模式画框宽 390px。
- 新窗口打开（`ExternalLink`），就绪时可用。
- 专注预览（`Maximize2` / `Minimize2`）：隐藏对话和工作台导航，预览占满右侧；`Esc` 退出；状态保存在编辑页 state。
- 「重新构建」「暂停预览」收进地址栏右侧 `⋯` 菜单，禁用条件与现在一致。

**画布**：

- 背景 `sunken`，内边距 24px（移动端 12px）。
- 桌面模式：白色画框 `max-width: 1200px`，宽 100%，高铺满可用空间，圆角 12px，`shadow-2`，iframe 在内滚动。
- 手机模式：画框 390px 宽居中，高铺满，圆角 20px，1px 边框，模拟手机屏幕；iframe 宽 100%。
- 预览背景始终白色，暗色主题下也不变。
- 就绪但显示的不是最新版本：画布上方一条 36px 提示「当前显示 v2 预览，v3 尚未准备」+「构建 v3」。
- 未就绪：画框位置显示紧凑空态，最大宽度 420px：
  - 40px 图标（进行中时 `Spinner`）。
  - 15px 标题：`正在生成应用` / `正在准备预览` / `这次生成还没完成` / `预览还没有准备好`。
  - 一句 12.5px 说明，最多两行。
  - 一个主按钮：`继续完善应用` 或 `重试预览`；失败时另附文字按钮「查看原因」。
- 不显示四步流程说明、双按钮堆叠和大标题。

### 5.6 工作台各分区

统一结构：`SectionHeader`（标题 + 右侧动作）→ 筛选行（可选）→ 卡片。卡片为白底、1px `line`、圆角 12px、`shadow-1`；列表行用 `borderTop` 分隔。

#### 数据分析

- 筛选行：环境分段「正式 / 测试」、时间分段「最近 1 天 / 7 天 / 30 天」、刷新。不新增自定义日期范围、小时维度和导出。
- 状态提示：仅当 `disabled` / `not_instrumented` / `partial` / `stale` 时显示一行说明，不用大面积 Alert。
- KPI 卡：`rowLabels` 的 10 个指标，响应式 2/3/5 列；标签 11.5px muted，数值 22px / 650；缺失显示 `—`，不显示伪造的 0。
- 趋势卡「每日浏览」：用无依赖的 CSS 柱状图展示 `data.daily`，带日期和数值 title；无数据时显示「当前时间范围内暂无数据」。
- 其他分布（来源渠道、设备、事件量）放在两列卡片里，每行名称 + 数值；无数据行显示「暂无数据」。
- 子标签「概览 / 转化 / 质量 / 版本」保留为分段或下划线标签，内容沿用现有逻辑，只统一卡片和字号。
- 核心目标、未接入提示、尚未收到浏览器事件等说明保留，但收进对应卡片底部，不再单独占行。

#### 数据库

```text
数据库                                      [正式数据] [测试数据]
表 [报名记录 ▾]                                      [刷新]
┌──────────────────────────────────────────────────────────┐
│ 姓名        邮箱                 报名时间                 │
├──────────────────────────────────────────────────────────┤
│ 陈          chen@example.com     10-28 10:12             │
└──────────────────────────────────────────────────────────┘
最近 100 条
```

- 选择环境或表后自动读取，右上「刷新」重新请求。
- 读取中 `Spinner`，失败 `Alert`，空表「暂无记录」，没有数据表时「这个应用还没有数据表」。
- 表格包在卡片内，表头 sticky，横向滚动只在卡片内部。
- 轮询详情不触发数据读取；只有环境、表、刷新变化时请求。

- 下线使用 `danger` 样式，放在状态卡内，不与发布并列；保留现有确认语义。
- 回滚沿用现有 `act("rollback", …)`，当前线上版本禁用。
- 地址复制使用 `navigator.clipboard`，失败时 toast；不新增域名能力。

#### 文件 / 操作记录 / 设置

- 文件：保留现有 `Files` 组件，外面加分区标题和统一卡片容器。
- 操作记录：单卡片列表，最近在上；每行操作类型、状态胶囊、时间、阶段；错误附一句用户文案 + mono 参考编号；「核对运行状态」「取消构建」保留在行内；空态「还没有操作记录」。
- 设置：卡片内应用名称（输入 + 保存）、应用编号（只读 + 复制）、说明文字（发布地址不随名称变化、预览 30 分钟回收、线上独立运行）。

### 5.7 对话区

- 桌面端常驻左侧，宽度 32%（360–480px），背景 `canvas`。
- 移除 `Chat embedded` 自带的 40px「开发会话」标题行；应用名称和状态已在顶栏，不再重复。
- 保留消息、工具时间线、思考折叠、反馈、草稿、停止本轮、附件、模型和环境选择。

### 5.10 无障碍

## 十、风险与取舍

| 风险 / 取舍 | 说明 | 缓解 |
| --- | --- | --- |
| 对话从 44% 收到 32% | 长消息阅读变窄 | 最小 360px；专注预览可进一步扩大右侧；对话可独立滚动 |
| 8 个标签变 7 个导航分区 | 习惯点标签的用户需要重新找 | 默认分区是数据分析；记录和设置各有固定入口；选中态明显 |
| 去掉常驻状态条 | 用户可能觉得进度变隐蔽 | 生成中保留顶栏状态胶囊 + 紧凑进度条；失败时才出现警告条 |
| 数据分析外壳重做 | 可能影响现有观测数据展示 | 只改容器和排版，不改请求、字段和诊断逻辑；逐项对照验收 |
| 数据自动读取 | 切换表会立即发请求 | 只在环境/表/刷新变化时请求，不随 1.5s 轮询触发 |
| 预览 iframe 在切模式时保持挂载 | 可能占用内存 | 只对预览模式使用 `display:none`，不重复创建；离开编辑页即卸载 |
| 与 v11 统一入口并行 | 两者都会改 `ApplicationsPage.tsx` | 本规格只动编辑页；若同时实施，先落地统一入口再改编辑页 |
