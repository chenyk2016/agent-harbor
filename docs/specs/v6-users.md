# V6：身份、权限、额度和用量

用户已批准会话中的方案并要求实施。本规格记录实现选择，不另加发布授权。

## 架构

延续单Node服务、SQLite、Docker及原生SDK。使用openid-client实现可配置OIDC授权码登录（PKCE、state、nonce、ID token核验），不自行维护密码。以issuer+sub映射内部UUID，不按邮箱合并账号。外部身份系统决定谁可以完成登录；首次登录建用户，不授管理员。

Cookie登录8小时，登录哈希持久化，重启保留；令牌过期/退出、密钥撤销、账号停用断开对应观看/传输。退出不取消任务，停用关闭用户全部环境。管理员ID由受信环境配置明确指定；不因第一个登录自动授管理员。

开发密钥文件启动导入SQLite，已撤销记录不能被再次导入复活。已有ownerId及用户数据保留，不自动合并到新OIDC用户。CLI保留Bearer，可在网页创建/撤销自己的长期CLI密钥（默认30天，仅显示一次）。

## 资源和用量

每用户默认100个保存会话、1个同时执行任务、2份保留环境，全局4份环境。管理员可调整每用户策略；不自动排队。去重先于额度检查；同步检查至accepted/内存占位之间无await。停机/状态未知不得提前释放环境占位。

工作区默认1GiB软额度：安全目录描述符扫描工作区，上传时按实际字节限制、用户上传占位阻止跨会话同时入库；开始新任务前检查。生成文件可超限，后台写入与扫描不形成事务；不是文件系统硬配额。不统计Claude状态/日志，不宣称整个用户磁盘硬隔离。

用量按messageId幂等保存，原生累计costUsd按会话基线做增量；累计下降或启动错误零值标记增量未知，保留此前基线；旧历史无基线时首条只建立观察值。token usage仅按原生每条result的主循环字段计入，费用是SDK估算，非账单或硬预算。保留费用来源及runnerId，重启不重复累计，不回填旧历史。

## 接口与界面

匿名：GET /api/auth/config，GET /api/auth/oidc/start、callback。原开发key登录保留，可配置禁用网页key登录。

本人：GET /api/account（用户、策略、实时占用、用量、空间）；GET/POST /api/account/keys；DELETE /api/account/keys/:id。

管理：GET /api/admin/users；PATCH /api/admin/users/:id（disabled或limits）。管理员由AH_ADMIN_USERS配置。提供薄管理CLI，不增加管理看板。

网页复用现有样式，增加SSO登录按钮、我的用量/密钥弹窗、明确额度错误。持久化身份、策略、密钥和用量在control.sqlite；凭证不发给容器、不进入日志/浏览器存储。使用配置AH_PUBLIC_ORIGIN推导回调和Origin，https下Secure；服务仍仅监听回环，HTTPS反代部署另验，不相信转发头。

## 验证

工程覆盖跨用户访问、同步并发占位/取消/未知停止、累计费用去重/重置、密钥撤销/过期、持久Cookie、停用关闭事件流和环境。OIDC以本机签名身份服务夹具核验完整重定向/换码/claims及失败路径，不等同实际企业身份供应商验收。浏览器验证账号弹窗和既有会话/文件入口。

不做组织共享、计费、分布式排队、硬盘硬配额、公开部署或自动注册外部身份应用。
