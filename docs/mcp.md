MCP 是让 Agent 调用工具的连接方式。例如，连接公司提供的查询服务后，Agent 可以在对话中读取获准的数据。Harbor 支持远程 HTTP 服务、管理员提供的本地模板，以及自己编写的 Node.js/Python 脚本。

添加前先确认工具来自可信服务，并准备服务地址和所需凭据。远程地址还需要管理员批准。

## 添加并测试连接

1. 打开「资料库 → MCP 连接」，点击「新建连接」。
2. 填写连接名称，选择连接类型。
3. 按下面的表格填写地址或选择工具，再填写所需的「凭据 JSON」。无需凭据时可留空。
4. 先取消勾选「启用此连接」并保存，再点击「测试连接」，查看发现的工具名称。测试只检查连接和工具列表，不调用模型或执行业务工具。
5. 确认工具范围后，勾选「启用此连接」并保存。在新会话中描述需要执行的操作。

| 连接类型 | 需要填写的内容 |
| --- | --- |
| 远程 MCP（HTTP） | 服务地址，以及服务要求的 HTTP 请求头 |
| 管理员本地模板 | 选择管理员提供的模板，填写它声明的参数 |
| 手写 MCP 脚本 | 选择已保存的个人或管理员脚本，填写它声明的参数 |

启用会允许 Agent 使用该服务提供的**全部工具，包括以后新增的工具**。需要限制访问范围时，应使用权限较小的上游账号或服务凭据。

## 示例：使用内置文本工具

默认本地模板「文本工具（离线）」（`text-tools`）提供字符统计和 SHA-256 摘要工具。

1. 新建连接，类型选「管理员本地模板」，模板选「文本工具（离线）」，无需填写凭据。
2. 保存、测试，确认工具列表中出现 `text_stats` 和 `sha256`。
3. 启用连接，在新会话发送：

   > 使用 text_stats 统计 Hello Harbor，并告诉我工具返回了什么。

在回答中核对字符数 **12**、行数 **1**、UTF-8 字节数 **12**，并在工具记录里确认出现 `text_stats` 调用。当前时间线显示的是调用已发起，不展示完整工具返回，也不能单独证明执行成功。连接测试只说明能发现工具，实际任务仍需核对回答或产物。

## 连接远程服务

服务地址示例为 `https://mcp.example.com/mcp`。如果服务要求 Bearer Token，在「凭据 JSON」中填写：

```json
{
  "Authorization": "Bearer replace-with-your-token"
}
```

凭据保存后不回显。编辑时留空表示保留，填写 `{}` 表示清空；更换服务地址时需要重新填写凭据。不要把密钥放进地址或脚本源码。

管理员通过 `AH_MCP_ALLOWED_ORIGINS` 批准服务所在的来源地址，例如 `https://mcp.example.com`。来源包含协议、主机和端口，不包含 `/mcp` 等路径。未获批准时，连接不能保存或启动；联系管理员确认后再试。此处的普通远程连接使用请求头凭据，不提供通用 OAuth 授权界面。

## 更新连接何时生效

修改连接、脚本或凭据后，当前正在执行的任务继续使用原配置。下一次发送消息前，Harbor 会重新加载所需环境，保留已有对话和工作文件；空闲时也可以从会话详情使用「重新加载 MCP」。

停用连接不会撤销已经提交到远程服务的操作。需要立即终止任务时，先使用「停止」，再到上游服务检查操作结果，必要时撤销凭据。

## 编写个人脚本

在「MCP 连接」点击「新建私有脚本」，填写脚本名称、运行时、入口文件和「文件 JSON」，保存后再创建脚本类型的连接。

脚本需要实现 MCP 的 stdio 协议，即通过标准输入和输出交换工具消息；普通命令行脚本不能直接作为 MCP 服务。标准输出只用于协议消息，调试日志应写到标准错误。

| 运行时与依赖准备 | 所需文件 |
| --- | --- |
| Node.js，无需额外依赖 | 入口脚本，例如 `server.mjs` |
| Node.js，npm | 入口脚本、`package.json`、`package-lock.json` |
| Python，无需额外依赖 | 入口脚本，例如 `server.py` |
| Python，uv | 入口脚本、`requirements.txt` |

需要密钥时，在「允许的环境参数」声明字段名，例如 `API_KEY`，再在连接的「凭据 JSON」中填写值。个人脚本仅本人可选，管理员脚本可供所有用户选择。

每个脚本包最多 100 个文件、总计 1 MiB，只接受相对路径。Node.js 依赖安装禁用安装脚本；较大的依赖可能导致连接准备超时，可请管理员预装。当前脚本页面支持创建和编辑，不提供源码版本回滚。

## 管理员提供本地模板

管理员可以把常用工具固定为模板，用户只需选择模板和填写参数。将模板 JSON 文件路径配置到 `AH_MCP_TEMPLATES_FILE`，例如：

```json
[
  {
    "id": "company-tool",
    "name": "公司工具",
    "command": ["/usr/local/bin/node", "/opt/company-tool/server.mjs"],
    "secretKeys": ["API_KEY"]
  }
]
```

命令使用绝对路径，程序和解释器须存在于 Agent 的运行镜像中。用户只能填写模板声明的参数，不能通过参数替换启动命令。

## 使用边界

本地工具在会话环境中运行，遵守该会话的文件、网络和资源限制；同一会话的工具可以接触共同的工作文件。远程工具实际操作发生在服务商一侧，Harbor 无法通过停止任务撤回已发生的写入。
