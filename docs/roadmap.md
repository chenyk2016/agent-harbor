# 实现范围与后续方向

本页区分当前源码已有的能力与尚未接入的方向。功能可配置不代表目标环境已经完成真实供应商或生产验收。日常使用从[产品文档](index.md)开始。

## 仍需独立设计或验收

- 持久执行队列尚未接入普通任务生产路径；[PostgreSQL队列规格](specs/postgresql-execution-queue.md)中的原型不等于正式功能。
- 尚无多主机调度、服务升级时任务无缝继续或高可用承诺。
- 组织共享、磁盘硬配额、对陌生多租户的完整隔离和容量验证仍需单独推进。
- 内置备份不包含独立应用业务库、观测库和外部目录；恢复后需补齐环境配置，不能代替完整部署恢复演练。
- 真实模型效果、供应商账单、真实OIDC/Google授权及目标部署安全，以对应环境的独立验收为准。

历史设计和版本实验保留在 `docs/specs/`、`docs/design/` 与原始验证记录中，不作为当前功能清单。
