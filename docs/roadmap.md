# 路线图

| 阶段 | 内容 | 状态 |
| --- | --- | --- |
| V1执行核心 | Docker、原生工具、工作区、resume、单会话锁与停止确认 | 已实现 |
| V2持续对话 | 同容器/Runner/原生进程连续输入、Keeper和异常重建 | 已实现 |
| V3独立服务 | 服务持有会话、HTTP/SSE、SQLite、开发身份、去重、重连、容量、空闲回收及重启协调 | 已实现，工程验证见testing |
| V3任务中断 | 原生中断保留环境，超时/异常兜底，明确关闭全环境 | 已实现，实际Docker/SDK验证 |
| 真实使用验收 | 获准网关、自主读改测、成本和用户目标 | 待实际部署验收 |
| V4网页 | macOS风格个人工作台、多行对话、历史/SSE、草稿、Cookie开发登录、中断/关闭 | 已实现，工程、浏览器与实际Docker/SDK分层验证 |
| V5文件工作区 | 上传/目录/文本预览/单文件下载、路径插入消息 | 已实现，验证见workspace-files与testing |
| V6身份与用户限制 | 可配置OIDC、持久Cookie、密钥撤销、账号停用、个人额度和用量观察 | 已实现；真实身份供应商与HTTPS部署另验 |
| 后续运营能力 | 队列、组织共享、硬预算/账单、短期模型凭证、事件保留和管理审计 | 未实现 |
| 高可用与生产隔离 | 服务升级时任务继续、多机调度、完整攻击/故障矩阵、磁盘配额与备份 | 未完成 |

本地开发密钥及会话归属检查不等于完整生产身份与租户隔离。每会话一个容器也不能替代内核、网络和文件系统安全验收。

## V7 React前端

React18 + Chakra UI2 + Vite独立apps/web工程，统一字号/颜色、会话导航、对话阅读区、文件与账户弹窗；保持后端/执行协议。详见[实现与开发](react-web.md)。
