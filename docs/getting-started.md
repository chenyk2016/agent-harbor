# 开始使用

根据你是使用工作台，还是负责部署，选择下面的路径。

## 已有团队工作台

1. 向管理员取得工作台地址和登录方式。
2. 登录后确认可以选择模型，并有可用额度。
3. 按 [第一个任务](first-task.md) 上传示例文件，下载并核对结果。

没有可选模型或额度时，请管理员开通；你不需要自行部署服务器。

## 自己安装 Harbor

1. [安装与启动](quickstart.md)：准备环境、初始化管理员、打开工作台。
2. [接入模型](llm-gateway.md)：填写供应商凭据，设置价格与使用范围，完成连接测试。
3. [第一个任务](first-task.md)：从上传到下载走完一次任务。
4. 需要多人使用时，再配置 [团队部署](deployment.md) 和 [登录方式](identity.md)。

应用创建、访客登录和模型观测按需配置。首次安装先完成文件任务即可，之后到 [配置与管理](manage.md) 开通需要的功能。
